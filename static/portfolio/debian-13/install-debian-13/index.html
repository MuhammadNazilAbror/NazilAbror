Install Debian 13

Debian 13 · Jobsheet Konfigurasi

1. Buat Virtual Machine Baru

Buka VMware Workstation, pilih Create a New Virtual Machine, lalu pilih Typical (Recommended). Klik Next.

Pilih Installer disc image file (iso), lalu klik Browse dan cari file ISO Debian 13 yang sudah kalian download. Klik Next.

Pada Guest Operating System pilih Linux, dan pada Version pilih Debian (versi 64-bit). Klik Next.

Beri nama Virtual Machine dan tentukan lokasi penyimpanannya. Klik Next.

Atur ukuran RAM (memory) untuk virtual machine, minimal 2 GB agar instalasi lancar / sesuaikan dengan kapasitas laptop masing-masing. Jika sudah, klik Finish untuk membuat VM.

2. Jalankan Virtual Machine dan Mulai Instalasi

Nyalakan (Power On) virtual machine yang sudah dibuat. Pada tampilan awal installer, pilih Graphical Install.

3. Pilih Bahasa, Lokasi, dan Tata Letak Keyboard

Pilih bahasa yang akan digunakan selama proses instalasi, Klik Continue.

Pilih lokasi tempat kalian berada. Zona waktu akan otomatis mengikuti lokasi ini. Klik Continue.

Pilih tata letak keyboard yang sesuai, Klik Continue.

Tunggu proses installer memuat komponen tambahan yang dibutuhkan.

4. Konfigurasi Jaringan (Hostname dan Domain)

Isi hostname atau nama untuk sistem kalian, misalnya debian. Klik Continue.

Isi domain name jika ada, atau kosongkan saja jika tidak digunakan. Klik Continue.

5. Tentukan Password Root

Masukkan password untuk akun root, disarankan pw nya yang singkat saja seperti 123 agar lebih mudah diingat, lalu ketik ulang untuk konfirmasi. Klik Continue.

6. Buat User Baru

Masukkan nama masing-masing untuk user baru (bukan root). Klik Continue.

Buat password untuk user baru tersebut, disarankan yang singkat seperti 123 agar mudah diingat, lalu ketik ulang untuk konfirmasi. Klik Continue.

7. Atur Zona Waktu

Pilih zona waktu yang sesuai dengan lokasi kalian. Klik Continue.

8. Partisi Hard Disk

Pilih metode partisi. Untuk pemula, pilih Guided - use entire disk agar partisi dibuat otomatis. Klik Continue.

Pilih disk yang akan dipartisi. Klik Continue.

Pilih skema partisi All files in one partition (recommended for new users). Klik Continue.

Periksa hasil partisi yang dibuat, lalu pilih Finish partitioning and write changes to disk. Lalu Continue saja.

Pilih Yes untuk menyimpan perubahan partisi ke disk.

9. Konfigurasi Package Manager

Pilih No. Klik Continue.

Pilih No untuk melewati penggunaan network mirror. Klik Continue.

Pilih No untuk melewati survei penggunaan paket.

10. Pilih Software yang Akan Diinstal

Pilih paket software yang ingin diinstal, disarankan untuk pemula install GUI saja dengan mencentang bagian :

  • Debian desktop environment

  • GNOME

  • standard system utilities.

Klik Continue.

11. Instal GRUB Boot Loader

Pilih Yes untuk memasang GRUB boot loader ke drive utama. Klik Continue.

Pilih device tempat GRUB akan dipasang, /dev/sda. Klik Continue.

12. Selesaikan Instalasi

Instalasi selesai. Klik Continue untuk reboot.

13. Login ke Debian 13

Sistem akan boot masuk ke Debian 13.

Pilih user yang sudah dibuat sebelumnya untuk login.

Masukkan password user tersebut.

Setelah berhasil login, kalian akan masuk ke tampilan desktop GNOME Debian 13.

14. Membuka Terminal

Buka aplikasi Terminal untuk mulai menjalankan perintah.

Gunakan perintah #su root lalu masukkan password root untuk masuk sebagai administrator (root).
